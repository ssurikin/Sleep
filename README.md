# Sleep

Отправляет Windows-ПК в сон, когда я отошёл надолго, - но только если в этот момент ничего не мешает: не идёт стрим, не открыт OBS, не смотрю видео. Обычные таймеры бездействия в таких случаях либо рано рубят машину, либо не срабатывают годами - этот скрипт написан под сценарий стримера с Voicemeeter и OBS.

Запускается по расписанию, молча проверяет систему и либо усыпляет ПК, либо сбрасывает отсчёт.

## Что проверяется перед сном

1. Физическое бездействие (мышь/клавиатура) - по умолчанию 15 минут.
2. Не запущен ли OBS (процесс `obs64`).
3. Нет ли активных запросов питания от программ (`powercfg -requests`, секция `[PROCESS]`).
4. Драйверы: виртуальным аудио-драйверам (Voicemeeter, USB Audio) разрешено не мешать сну, всё незнакомое сон блокирует. Разрешения оформляются через `powercfg -requestsoverride`.
5. Активное окно: если на переднем плане браузер или плеер - считается, что идёт просмотр видео.
6. Все проверки должны проходить непрерывно 15 минут подряд, счётчик «чистого» времени хранится в `sleep_state.json`.

Только после этого выполняется `rundll32.exe powrprof.dll,SetSuspendState 0,1,0`.

## Установка

1. Скопировать папку скрипта на постоянное место, например `C:\CustomScripts\Sleep`.
2. Создать задачу в Планировщике задач с запуском раз в 5 минут:

   ```
   powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "C:\CustomScripts\Sleep\custom_sleep.ps1"
   ```

3. Если окно консоли при запуске мигает - указать в задаче `run_sleep_hidden.vbs`, он запускает скрипт полностью скрыто. Путь внутри `.vbs` поправить под свою папку.

## Настройки

Все параметры - в начале `custom_sleep.ps1`, в блоке `SETTINGS`:

| Переменная | Значение по умолчанию | Что делает |
|---|---|---|
| `$targetMinutes` | `15` | Сколько минут бездействия нужно до сна |
| `$enableLogging` | `$true` | Писать ли лог в `sleep_log.txt` |
| `$mediaProcesses` | браузеры и плееры | Какие процессы на переднем плане считать «смотрю видео» |

## Файлы

- `custom_sleep.ps1` - сам скрипт
- `run_sleep_hidden.vbs` - скрытый запуск для планировщика
- `sleep_log.txt`, `sleep_state.json` - создаются при работе, в репозиторий не входят
